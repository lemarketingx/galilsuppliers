# Galil Suppliers Directory V3

אתר מאגר ספקים לגליל הנדסה.

## הרצה
```bash
npm install
npm run dev
```

## פורמט Excel נתמך
המערכת מזהה אוטומטית שמות עמודות נפוצים, כולל:
- שם ספק / ספק / שם הספק
- תחום / תחום פעילות / קטגוריה / תאור משאב / תיאור משאב
- איש קשר
- טלפון / נייד
- מייל / אימייל
- מיקום / עיר / מדינה / כתובת
- מק"ט / מק״ט / קוד ספק / מספר ספק
- סטטוס
- דירוג
- הערות

## יכולות
- העלאת Excel
- חיפוש לפי שם ותחום
- סינון לפי תחום וסטטוס
- מחיקת ספק מהמערכת
- דירוג ספקים 1-5 כוכבים
- שמירה אוטומטית בדפדפן
- ייצוא Excel
