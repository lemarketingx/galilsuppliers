# Galil Engineering Suite V5

כולל:
- שתי לשוניות: מחירון / BOQ ומאגר ספקים
- עיצוב בהיר זהה לגרסה הקודמת
- העלאת Excel למחירון לפי כל הלשוניות: כל לשונית הופכת לדיסציפלינה
- דיסציפלינות ברירת מחדל: צנרת, חשמל, כיבוי אש, מיזוג אויר, הנדסה אזרחית, מכשור
- הוספת דיסציפלינה ידנית
- מחיקת דיסציפלינה נבחרת
- סל חישוב, שמירה, יצוא Excel, יצוא PDF
- מאגר ספקים עם העלאת Excel, חיפוש, דירוג, מחיקה וסיווג ידני
