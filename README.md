# Galil Engineering Suite V2 Light

אתר מאוחד עם שתי לשוניות:
1. מחירון / BOQ
2. מאגר ספקים

## התקנה
```bash
npm install
npm run dev
```

## פריסה ב-Vercel
Framework: Vite
Build Command: npm run build
Output Directory: dist

## יכולות
- עיצוב בהיר
- העלאת Excel למחירון לפי עמודות בעברית
- העלאת Excel למאגר ספקים לפי הפורמט שלך
- סיווג ספקים אוטומטי לפי תחום עיסוק / שם / תיאור
- מחיקת ספק
- דירוג ספקים
- תיקון ידני של דיסציפלינה
- שמירה בדפדפן
- ייצוא Excel
- ייצוא PDF עם לוגו במחירון
