# Galil Suppliers Directory V6 Smart

מערכת ספקים חכמה לקבוצת גליל:
- העלאת Excel בפורמט ספקים
- סיווג אוטומטי לפי שם ספק / תחום עיסוק / תיאור
- תיקון ידני של דיסציפלינה
- למידת תיקונים ושימוש חוזר בהם
- דירוג ספקים בכוכבים
- מחיקת ספקים
- שמירה בדפדפן LocalStorage
- ייצוא Excel

## התקנה
npm install
npm run dev
