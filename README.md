# Galil Suppliers Directory V2

אתר מאגר ספקים לגליל הנדסה.

## הפעלה מקומית
```bash
npm install
npm run dev
```

## העלאת Excel
המערכת מזהה עמודות בעברית/אנגלית:
- שם ספק / ספק / Supplier
- תחום / דיסציפלינה / Category
- איש קשר / Contact
- טלפון / Phone
- אימייל / Email
- עיר / מיקום / Location
- סטטוס / Status
- דירוג / Rating
- הערות / Notes

יש כפתור להורדת תבנית Excel מתוך האתר.
